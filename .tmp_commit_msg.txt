Always launch helper regardless of DualSense trigger settings

The helper (frdx-helper.exe) is now always launched when the game
starts and never stopped while the game is running. It's needed for
texture injection (artwork downloads, texconv BC7 compression) in
addition to DualSense triggers.

Changes:
- maybe_launch_external_helper: removed the
  dualsense_external_helper_should_launch gate — always launches
  if the helper isn't already running
- bridge startup: removed the forced external_helper config patch
  and the stale helper stop when triggers are disabled
- store.on_change callback: removed stop_external_helper() call
  when triggers are toggled off; helper stays alive

The DualSense enabled toggle now only controls trigger functionality
within the helper, not the helper's existence.
